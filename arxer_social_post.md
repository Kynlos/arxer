# 📚 Arxer - AI-Powered ArXiv Research Assistant

Hey everyone! Just finished building **Arxer**, a tool to help researchers explore ArXiv papers with AI assistance. Check out what it can do:

## ✨ Key Features

### 🔍 Smart Search
- Advanced query syntax (`author:"Name"`, `title:"Text"`, date ranges)
- Auto-categorization of papers by topic
- Multiple sorting options (relevance, date, title)
- Generate citations in any format (BibTeX, APA, MLA, etc.)

### 🤖 AI Research Assistant
- Chat with AI about papers or research topics
- Load papers from your collections as context
- Get explanations of complex concepts
- Connect ideas across multiple papers

### 🕸️ Knowledge Graph
- Visualize connections between papers & concepts
- Identify related research clusters
- Interactive network exploration
- Toggle between different visualization modes

### 📂 Paper Management
- Save papers to custom collections
- Track search history
- Organize research by project

### 🧠 Understanding Tools
- AI-generated summaries
- Key concept extraction
- Math equation rendering (LaTeX support)

## 🛠️ Tech Details

- Works with multiple AI providers:
  - **LocalLM**: Run models locally for privacy (uses LM Studio) - Best for Citations and Summaries (using 1.1b models)
  - **OpenAI**: Connect to OpenAI/OpenAPI based APIs for powerful responses

- Built with PHP + JavaScript (no complex framework dependencies)
- Responsive design works on desktop, tablet & mobile
- Easy self-hosting - just needs a basic web server
